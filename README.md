# المثبّت الأونلاين لصانع الفيديو

[تنزيل المثبّت الأونلاين مباشرة](https://github.com/Mustafa-Elbheri/VideoMakerOnlineInstaller/releases/latest/download/VideoMakerOnlineSetup.exe)

ينزّل هذا المثبّت أحدث إصدار منشور من صانع الفيديو من مستودع [إصدارات البرنامج](https://github.com/Mustafa-Elbheri/VideoMaker/releases/latest)، ثم يشغّل تثبيته.

يتطلب اتصالًا بالإنترنت، وويندوز 10 محدّثًا أو ويندوز 11. قد يطلب ويندوز صلاحيات المسؤول عند بدء تثبيت البرنامج.

يدعم واجهة عربية وإنجليزية وفرنسية، ويعرض حالة التنزيل في حقل نصي للقراءة، مع زر لإيقاف التنزيل باستخدام لوحة المفاتيح.

الرابط المباشر أعلاه ثابت، ويشير إلى أحدث نسخة منشورة من المثبّت في هذا المستودع.
